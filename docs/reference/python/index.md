# Python API

The public API is the `popcorn` package and the `popcorn.pytest` plugin. Names not listed here are
private.

- [Machines](machines.md): `Machine`, calls, stops, snapshots, tracing and coverage.
- [Images](images.md): `Elf`, `Bin`, `Hex` and symbols.
- [Peripherals](peripherals.md): registers, pins, boards, devices and Python models.
- [Links and taps](links.md): `System`, `UartLink` and `UartTap`.
- [Hooks](hooks.md): intercepts, probes, watches and conditions.
- [Errors](errors.md): the exception tree.
- [Descriptions](descriptions.md): `MachineDescription` and its parts.
- [pytest plugin](pytest.md): fixtures and settings.
